# Carousify

> Create and preview social-media carousel designs right in your browser.

[**OPEN THE LIVE DEMO**](https://rajpurohitkushal92.github.io/Carousify/)

## About

Carousify is a browser-based creative tool for putting together and previewing carousel designs. Explore a visual idea, review how the slides flow, and shape it into a shareable post.
